# خادم سدد ولوحة الأدمن

يحتوي هذا المجلد على REST API متعددة المتاجر ولوحة إدارة عربية محمية. الحسابات العامة غير مفتوحة: ينشئ الأدمن كل حساب متجر ويرسل كلمة مرور مؤقتة لصاحبه.

## نشره على خادم

1. جهّز نطاقاً يشير إلى الخادم، واسمح باتصالات المنافذ 80 و443.
2. انسخ `.env.example` إلى `.env`.
3. عيّن `DOMAIN` إلى نطاق API الحقيقي، وأنشئ مفتاح تشفير ثابتاً من 32 بايت لربط WhatsApp. مثال لإنشاء المفتاح على Linux:

   ```sh
   openssl rand -hex 32
   ```

4. شغّل `docker compose up -d --build`.
5. على قاعدة بيانات جديدة، افتح `https://نطاقك/` وسجّل الدخول بالبيانات الفريدة التي وضعتها في `.env`. كلمة مرور الأدمن يجب أن تكون بين 12 و128 محرفًا. إذا استخدمت شاشة تأسيس الأدمن، احذف `INITIAL_ADMIN_KEY` من إعدادات الخادم بعد الإنشاء. لا توجد بيانات دخول افتراضية في ملفات المشروع.
6. من لوحة الأدمن أنشئ متجرًا، وامنحه اسم المستخدم وكلمة مرور مؤقتة. عند الدخول الأول يطلب التطبيق تغيير كلمة المرور.
7. ابنِ إصدار Android مع رابط API العام:

   ```powershell
   .\gradlew.bat assembleRelease -PSADAD_API_BASE_URL=https://api.your-domain.example/api
   ```

SQLite محفوظة في volume مستقل. خذ نسخاً احتياطية مشفّرة من ذلك الـ volume، واحتفظ بمفاتيح `.env` خارج النسخ العامة. حذف متجر من اللوحة حذف نهائي لبياناته وجلساته.

## لوحة التحكم

- إعداد الحزمة ينشئ مدير المنصة تلقائياً على قاعدة بيانات جديدة فقط، باستخدام `INITIAL_ADMIN_USERNAME` و`INITIAL_ADMIN_PASSWORD` من `.env`، ويجبره على تغيير كلمة المرور عند أول دخول. لا يعيد التشغيل تعيينها إذا كان هناك مدير مسجل.
- لاستخدام الإعداد اليدوي القديم بدلاً من الحساب التلقائي، اترك متغيري اسم المستخدم وكلمة المرور فارغين، واضبط `INITIAL_ADMIN_KEY` ثم أنشئ مديراً من صفحة التأسيس.
- إنشاء المتاجر، إعادة كلمة المرور المؤقتة، إيقاف الحساب مؤقتاً أو حتى إعادة تفعيله، إعادة التفعيل والحذف النهائي.
- تغيير حد الأشخاص ذوي الديون المفتوحة، تشغيل/إيقاف الميزات، ومنح شارة موثوق للأدمن فقط.
- مراجعة الملخصات وكشوف الحساب وتصدير CSV.
- بيانات المتجر وسجلاته مفصولة حسب store ID، وAPI يتحقق من الصلاحيات وحالة الحساب عند كل طلب.
- يرفض الخادم تعديل دين أو دفعة مسجلة، ويرفض حذف الدين الذي عليه رصيد، ويحسب سقف المدينين من مبالغ قاعدة البيانات. تُسجل أوقات وصول الدفعات على الخادم لمنع تكرار الدفعات القريبة حتى لو غيّر العميل وقتها.
- محاولات الدخول محدودة لكل عنوان شبكة ولكل حساب، والحد محفوظ في قاعدة البيانات حتى بعد إعادة تشغيل الخادم. كلمات مرور الأدمن يجب أن تكون 12–128 محرفًا.
- تستخدم حاوية Docker مستخدمًا غير root، وCaddy يمرر عنوان العميل في ترويسة يعيد كتابتها الخادم الوكيل. إذا غيّرت الوكيل، لا تثق بترويسة IP إلا بعد ضبطه ليحذف أي قيمة واردة ويكتب العنوان الحقيقي بنفسه.

## ربط WhatsApp

يفعّل الأدمن ميزة WhatsApp لكل متجر على حدة. بعد ذلك يدخل صاحب المتجر **Phone Number ID** ورمز وصول WhatsApp Cloud API من Meta من صفحة الربط داخل التطبيق. يخزن الخادم رمز الوصول مشفراً بمفتاح `TOKEN_ENCRYPTION_KEY` ولا يعيده للتطبيق بعد الحفظ. يجب كتابة أرقام المستلمين بالصيغة الدولية وتسجيل موافقتهم قبل إرسال الكشف.

يحتاج الإرسال إلى إعداد تطبيق WhatsApp Business Platform/Cloud API لدى Meta، رقم مرسل مسجل، وصلاحية رسائل ملائمة لقواعد Meta. ضع إصدار Graph API المدعوم في `META_GRAPH_VERSION`؛ لا يخمّن التطبيق الإصدار تلقائياً. لا يمكن تفعيل إرسال حقيقي قبل إضافة بيانات Meta ومراجعة حساب/تطبيق Meta.

## تشغيل محلي للتطوير

يتطلب Node.js 24 أو أحدث:

```sh
cp .env.example .env
```

املأ الأسرار في `.env` ثم شغّل `node server.js`. يضبط مشروع Android افتراضياً `http://10.0.2.2:8080/api` لمحاكي Android Emulator فقط. للأجهزة الحقيقية استخدم عنوان HTTPS منشوراً.

## ملاحظات تشغيلية

- غيّر كلمة المرور المؤقتة مباشرة بعد أول دخول، واستبدل مفاتيح المثال في `.env`، واضبط HTTPS والنسخ الاحتياطي قبل استخدام الخادم على الإنترنت.
- لا ترفع `.env` أو `data/sadad.sqlite` إلى مستودع أو موقع عام. شغّل الحاوية بصلاحية مستخدم `node` غير root، وخزّن قاعدة SQLite والنسخ الاحتياطية على قرص مشفر ومقيد الصلاحيات.
- إذا كان لديك volume Docker قديم مملوك لـ root، امنح مستخدم `node` صلاحية الكتابة إلى مجلد البيانات قبل الترقية.
- قفل PIN في التطبيق يضيف تأخيرًا تدريجيًا بعد المحاولات الفاشلة، لكنه لا يشفر قاعدة SQLite محليًا. أمن بيانات الهاتف يعتمد على قفل الجهاز وتشفير Android؛ لا تستخدم جهازًا مروّتًا أو مفتوحًا مع بيانات حقيقية.
- التخزين في هذه النسخة SQLite على خادم واحد؛ انقل قاعدة البيانات إلى PostgreSQL وخدمة جلسات مشتركة قبل توزيع النظام على عدة خوادم أو أحجام كبيرة.
- التطبيق يزامن دفتر المتجر الكامل عند الحفظ. إصدار المزامنة يمنع جهازاً قديماً من الكتابة فوق بيانات أحدث، لكنه يتطلب أن يعيد المستخدم تحميل النسخة الأحدث عند تعارض جهازين.
