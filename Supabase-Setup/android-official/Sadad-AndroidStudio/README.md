# سدد — تطبيق Android وخادم ولوحة إدارة

الحزمة تجمع مشروع Android Studio، وواجهة عربية RTL، وخدمة API متعددة المتاجر، ولوحة إدارة محمية. افتح مجلد المشروع هذا في Android Studio؛ لا تفتح مجلد `app` وحده.

## محتويات المشروع

- `app/`: تطبيق Android، أصول الواجهات، وقاعدة بيانات SQLite المحلية.
- `server/`: خادم Node.js، لوحة إدارة المتاجر، إعداد Docker وHTTPS، وتعليمات النشر في `server/README.md`.
- `artifacts/Sadad-debug.apk`: نسخة تجريبية جاهزة للمحاكي أو التثبيت اليدوي.

## فتح التطبيق

1. فك الضغط وافتح مجلد `Sadad-AndroidStudio` من Android Studio.
2. وافق على تنزيل Android SDK 36 إذا طلبه Android Studio، ثم انتظر Gradle Sync.
3. شغّل الخادم الموضح أدناه، وأنشئ حساب المتجر من لوحة الأدمن.
4. في شاشة الدخول، اضبط عنوان API المنشور عبر HTTPS. العنوان الافتراضي `10.0.2.2` يعمل مع Android Emulator فقط.

لبناء APK تجريبي جديد من PowerShell:

```powershell
.\gradlew.bat assembleDebug
```

مسار الناتج: `app\build\outputs\apk\debug\app-debug.apk`. إعداد مفتاح توقيع إصدار الإنتاج يعتمد على مفتاح المالك؛ لذلك الأرشيف لا يوقّع إصدار Release بمفتاح غير متوفر.

## الوظائف

- شعاران مطابقان للصور المرفقة، مع تبديل شعار وألوان الوضع الفاتح والداكن.
- الواجهات محلية وسريعة، والتحويل بينها عبر Android، مع قفل التكبير والتمرير الأفقي.
- حسابات المتاجر ينشئها الأدمن. الدخول الأول يفرض استبدال كلمة المرور المؤقتة.
- الديون والدفعات وجهات الاتصال تحفظ محلياً وتزامن مع الخادم عند الاتصال. توجد صلاحيات وحدود لكل متجر.
- قفل اختياري برمز محلي مشتق ومخزن بصورة آمنة، مع مصادقة Android بالبصمة أو الوجه عند توفرها.
- مركز استحقاقات يعرض القيود ذات تواريخ الاستحقاق المسجلة، وكشوف قابلة للتصدير والمشاركة.
- شارة التوثيق وإيقاف الحساب وجدولة التجميد والحذف النهائي يتحكم بها الأدمن.
- WhatsApp Business Cloud API مضبوط لكل متجر على حدة؛ تخزن رموز Meta مشفرة على الخادم.

## تشغيل الخادم ولوحة الأدمن

اقرأ `server/README.md`. يحتاج النشر إلى نطاق، وخادم Docker، ومفتاح تأسيس للأدمن، ومفتاح تشفير، وإعداد HTTPS. تسجيل الدخول إلى لوحة الأدمن يتطلب حساب مدير أنشئ على الخادم.

إرسال WhatsApp الحقيقي يحتاج حساب Meta Business فعالاً، ورقم مرسل مسجلاً، وإصدار Graph API، وقوالب معتمدة عند الإرسال خارج نافذة المحادثة. هذه المفاتيح لا تأتي مع الحزمة ويضيفها مالك الحساب.
