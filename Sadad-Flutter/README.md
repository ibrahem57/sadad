# سدد — Flutter

تطبيق متجر مكتوب بلغة Dart بواجهات Flutter أصلية لـ Android وiOS.

ابدأ بـ [دليل التحويل والتشغيل](MIGRATION.md). يوضح الدليل الميزات، حسابات التجربة، بناء التطبيق، حالة Supabase، وما يلزم لنقل البيانات القديمة.

```sh
flutter pub get
flutter run --flavor demo --dart-define=SADAD_DEMO=true
```

دخول متجر التجربة: **123 / 123**.

النسخة الرسمية تحتاج استكمال API سجل v3 ونشره؛ لا يوجد ادعاء أنها جاهزة للإنتاج. ملفات iOS مجهزة للبناء على Mac، ولم تُبنَ على Windows.
